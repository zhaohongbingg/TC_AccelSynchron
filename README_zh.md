# TC_AccelSynchron

[English](README.md) | 简体中文

**匠魂冶炼炉 / 熔铸炉超频加热砖**

TC_AccelSynchron 是 Minecraft 1.20.1（Forge）的独立匠魂附属模组，提供可调倍率的超频方块。把它贴在冶炼炉或熔铸炉控制器正上方，整个结构就会熔炼得更快——不需要换控制器、改配方，也不用动多方块墙体。

## 特性

- **两种方块，两种风格**：焦黑超频加热砖用于冶炼炉，焦褐超频加热砖用于熔铸炉。两种方块对两种控制器都生效，只是外观不同。
- **可调速度**：右击循环切换 **1× / 2× / 4× / 8× / 16×** 熔炼速度，潜行右击反向切换；`1×` 即关闭超频。
- **独立燃料平衡**：燃料消耗由 `tc_accelsynchron-common.toml` 单独控制，可以保持原版燃料经济、让超频更费燃料，或让它更省燃料。
- **可视反馈**：倍率越高核心越亮；接上炉子时方块会点亮。
- **不使用 Mixin**：加速逻辑全部在超频砖自己的方块实体里，直接调用匠魂公开的熔炼与燃料模块，与其他匠魂附属兼容性更好，也不会引发 Mixin 冲突。
- **服务端运行**：加速逻辑在服务端；客户端只需要模组提供模型和提示。

## 使用方法

1. 合成一个**超频加热砖**（配方可在 JEI 中查看）。
2. 把它放在**冶炼炉或熔铸炉控制器正上方**。必须贴着控制器——放在墙上或炉顶不会生效。
3. 右击方块选择倍率，动作栏会显示类似 `超频频率：4×` 的提示。
4. 照常往炉子里放物品，即可看到熔炼变快。

超频砖只在控制器结构成型、且炉内有燃料时生效。拆掉方块或调到 `1×` 即恢复正常速度。

## 配置

燃料行为在 `config/tc_accelsynchron-common.toml` 中配置：

```toml
# 各速度档位的燃料消耗倍率。
# 默认与速度档位相同，因此每件物品消耗的燃料不变。
overclockFuelX2 = 2.0
overclockFuelX4 = 4.0
overclockFuelX8 = 8.0
overclockFuelX16 = 16.0

# 全局燃料系数：乘在上面四个档位值之上。
# 1.0 = 不额外调整；1.5 = 所有档位燃料再 ×1.5。
overclockFuelFactor = 1.0
```

每件物品的燃料消耗倍数为：

```
每件物品燃料倍数 = 燃料倍率 ÷ 速度倍率
```

示例：

| 速度 | 燃料设置 | 熔炼速度 | 每件物品燃料 |
|---|---|---|---|
| 4× | 4.0（默认） | 4× | 不变 |
| 4× | 6.0 | 4× | 1.5× |
| 4× | 2.0 | 4× | 0.5× |
| 16× | 16.0 + 全局系数 2.0 | 16× | 2× |

修改配置后需要重启游戏/服务器生效。

## 兼容性说明

- 本方块**刻意不实现**匠魂的多方块从属组件（servant），不会和控制器争抢 `in_structure` 状态。它仍被加入冶炼炉/熔铸炉相关的方块标签，所以也可以当作装饰性焦黑/焦褐砖放进墙体；但**加速只认控制器正上方**。
- 实际 modid 是 `tc_accelsynchron`（Forge 要求全小写），显示名为 `TC_AccelSynchron`。
- 本模组与 SlimeKnights 无隶属关系；匠魂与 Mantle 是它们各自的项目。

## 构建

```bash
# Windows
gradlew.bat build

# Linux / macOS
./gradlew build
```

产物位于 `build/libs/tc-accelsynchron-0.1.0.jar`，与匠魂、Mantle、JEI 一起放进 `mods/` 即可。
